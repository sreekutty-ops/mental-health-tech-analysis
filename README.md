# 🧠 Mental Health in Tech Survey — Analysis & Prediction

> Exploring how workplace culture, benefits, and personal factors influence mental health treatment-seeking behaviour among tech employees.

---

## 📌 Overview

This project analyses the **OSMI Mental Health in Tech Survey** dataset to uncover patterns in mental health treatment-seeking across the technology industry. It combines exploratory data analysis, data visualisation, and machine learning to answer key research questions.

**Dataset:** [OSMI Mental Health in Tech Survey](https://www.kaggle.com/datasets/osmi/mental-health-in-tech-survey)  
**Rows:** 1,259 responses | **Columns:** 27 features  
**Tools:** Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

---

## 🎯 Objectives

Identify workplace and personal factors associated with mental health treatment among tech employees.

---

## ❓ Key Research Questions

| # | Question |
|---|----------|
| 1 | What percentage of tech employees seek mental health treatment? |
| 2 | Does family history influence treatment-seeking behaviour? |
| 3 | Do workplace benefits and support affect mental health openness? |
| 4 | Are remote workers more or less likely to report mental health interference? |

---

## 📊 Key Findings

- **~50%** of tech employees sought mental health treatment
- Employees with a **family history** of mental illness are significantly more likely to seek treatment
- Companies that provide **mental health benefits and care options** show higher treatment rates
- **Family history** and **work interference** are the top predictors in the ML model
- Workplace support factors are nearly as predictive as personal history

## 🤖 Machine Learning Results

Three classification models were trained to predict whether an employee seeks mental health treatment.

| Model | Accuracy | ROC-AUC | CV Accuracy |
|-------|----------|---------|-------------|
| Logistic Regression | ~0.76 | ~0.83 | ~0.75 |
| Decision Tree | ~0.74 | ~0.80 | ~0.73 |
| **Random Forest** | **~0.78** | **~0.86** | **~0.77** |

**Best model:** Random Forest  
**Top predictors:** `family_history`, `work_interfere`, `benefits`

> Note: Exact scores depend on your dataset version. Run `03_model.ipynb` to see your results.

## ▶️ How to Run

**1. Clone the repo**
```bash
git clone https://github.com/YOUR_USERNAME/mental-health-tech-analysis.git
cd mental-health-tech-analysis
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Download dataset**

Go to [Kaggle OSMI dataset](https://www.kaggle.com/datasets/osmi/mental-health-in-tech-survey), download `survey.csv`, and place it in the `data/` folder.

**4. Run notebooks in order**
```bash
jupyter notebook
```
Open and run:
1. `notebooks/01_eda.ipynb`
2. `notebooks/02_viz.ipynb`
3. `notebooks/03_model.ipynb`
